## API rules (enforced by the CLI)

**Request format**
- **Query by distribution ID, not `/{datasetId}/0`.** The CMS edge blocked the `/0` form for `mj5m-pzi6` for every client (2026-10-26). The distribution ID changes when CMS refreshes data, so the CLI looks it up from the metastore on each run.
- **Send an identifying User-Agent.** Node's default ("node") gets HTTP 403. The CLI identifies itself honestly.
- **`in` lists must be repeated `conditions[i][value][]=` parameters.** A comma-joined string silently returns 0 rows.

**Behavior**
- **Unknown columns fail loudly here** (HTTP 400 "Column not found"), unlike data-api.
- **`limit` max is 1500.** Responses are `{results, count, schema}`.
- **Speed:** large datasets (`clinicians`, `facilityAff`) take about 13-15 s per request whatever the size. Batch 50-100 NPIs per `--in`. Small ones answer in about 1 s.

## Reading the numbers correctly

**Affiliations**
- **A clinician can have several practice enrollment rows.** Pick the one whose city, state and zip match their claims address. Don't take the first row.
- **A clinician can be affiliated with several hospitals.** Per-hospital rollups overlap and can't be summed.

**Hip/knee complications (`COMP_HIP_KNEE`)**
- It covers a multi-year window. Read `start_date` and `end_date`, and never call it annual.
- `score` is a rate (%). `denominator` is the measure cohort for that window, which CMS's measure methodology defines as Medicare fee-for-service elective primary hip/knee replacements (confirm before citing). It is not the hospital's total joint-replacement volume.
- "Not Available" plus a footnote means suppressed or too few cases. It is not zero.

**ASC quality columns (`ascNN_*`)**
- These map to CMS ASC measure numbers. For orthopedic work, `asc17_*` is CMS's hospital-visits-after-orthopedic-ASC-procedures measure, and `asc17_total_cases` is that measure's case count.
- Confirm each measure's definition in the dataset's data dictionary (linked from data.cms.gov/provider-data) before citing it. I haven't verified the number-to-measure mapping column by column.
